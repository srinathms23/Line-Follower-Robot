## 📌 Project Overview

The Line Follower Robot is an autonomous robotic system designed to detect
and follow a predefined path using IR sensors. An Arduino microcontroller
processes the sensor inputs and controls the motors through a motor driver
to maintain the robot's movement along the detected line.

## 🎯 Objectives

- Detect the line using IR sensors
- Process sensor inputs using Arduino
- Control motor movement based on sensor readings
- Implement autonomous path following
- Understand embedded-system and robotics integration

## 🛠️ Technologies Used

- Arduino
- Embedded C/C++
- IR Sensors
- Motor Driver
- DC Motors
- Arduino IDE
